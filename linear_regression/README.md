# Linear Regression from Scratch

A foundational machine learning project implementing **Multivariate Linear Regression from Scratch** in Python using NumPy and Pandas.

## Features Implemented from Scratch

- **Data Loading & Preprocessing**: Handling missing values, bias term ($x_0 = 1$) column insertion, and Z-score standardization.
- **Closed-Form Normal Equation**: Exact analytical parameter fitting with optional $L_2$ Ridge regularization.
- **Batch Gradient Descent**: Iterative gradient calculation, customizable initialization (`zeros`, `random`, `large_random`), learning rates, and early stopping tolerances.
- **Polynomial Feature Expansion**: General degree polynomial expansion for modeling non-linear trends.
- **Ridge Regularization ($L_2$)**: Loss penalty and gradient updates to mitigate multicollinearity and prevent overfitting.
- **Evaluation Metrics**: Custom functions for Mean Squared Error (MSE) and $R^2$ score.
