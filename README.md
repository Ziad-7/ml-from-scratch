# Machine Learning From Scratch

This repository contains implementation of fundamental machine learning models
in Python using Numpy and Pandas.

## Covered Models

- Linear Regression
- Logistic Regression

## Features Implemented

- Data Standardization (Z-score)
- Polynomial Features
- L2 Ridge Regularization
