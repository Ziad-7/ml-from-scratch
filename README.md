# Machine Learning From Scratch

This repository contains implementation of fundamental machine learning models
in Python using Numpy and Pandas.

## Covered Models

- Linear Regression
- Logistic Regression

## Features Implemented

- Data Standardization (Z-score)
- Polynomial Features
- L2 Ridge Regularization

## How to Run
1. Install Dependancies:
```bash
pip install -r requirements.txt
```

2. Run an Experiment:
```bash
python experiments/experiment1.py
```
